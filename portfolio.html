Human Resource Management System

Solo Choicez (Pvt.) Ltd — Laravel, MySQL, Bootstrap

An internal HRMS used by the HR team to manage employee records, daily attendance, leave requests, and company policies in one place. Because I had already worked in HR administration at the same company, I understood the manual process the system was replacing.

My work covers the database schema, Eloquent models and relationships, the controllers and validation behind each module, and the Blade screens the HR team actually uses. Authorization and middleware control who can see which employee records.

Laravel MySQL Eloquent Blade Bootstrap

What Goes Into Each Project

The same four things, whether it's a university project or a production system

01

Real Requirements

I start from the workflow the system has to support, not from a feature list, so the data model matches how people actually work.

02

Solid Schema

Tables, relationships, and migrations are designed before the first controller, so the structure holds up as the project grows.

03

Working Slices

Each feature ships end to end — backend, validation, and interface — so there's always something real to review.

04

Maintainable Result

Conventions are followed and logic sits where the next developer expects it, so handover doesn't require a long explanation.
